EV Charging Station Finder & Booking System

Project Description

It is a fully developed web application which allows people to find electric vehicle charging stations and book charges for their vehicles at any time.

The application allows users to:

* View charging stations
* Search for stations
* Filter stations
* View station information
* Select a charging station
* Make a booking
* View bookings
* View individual booking details
* Update bookings
* Cancel bookings
* View booking status

* Technologies Used -

a. Frontend

* HTML
* CSS
* JavaScript
* DOM Manipulation
* Fetch API

b. Backend

* Node.js
* Express.js
* REST APIs
* JSON

The EV Charging Station Finder & Booking System provides a simple and user-friendly way to find charging stations and manage bookings.
