# EV Charging Station Finder & Booking System

## Project Description

This project is a beginner-friendly full stack web application for finding electric vehicle charging stations and making charging bookings.

The application allows users to:

- View charging stations
- Search for stations
- Filter stations
- View station information
- Select a charging station
- Make a booking
- View bookings
- View individual booking details
- Update bookings
- Cancel bookings
- View booking status

## Technologies Used

### Frontend

- HTML
- CSS
- JavaScript
- DOM Manipulation
- Fetch API

### Backend

- Node.js
- Express.js
- REST APIs
- JSON
