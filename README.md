EV Charging Station Finder & Booking System

Project Description

It is a full-stack web application which allows people to find electric vehicle charging stations and book charges at them.
This project is included in the Full Stack Development Capstone Assessment and consists of a system which is used for finding and booking EV charging stations.
The program enables users to locate charging stations, search for them and filter the results, see information about the stations, make charging bookings, view the details of their bookings, modify their bookings and cancel them.
The frontend is developed using HTML, CSS and JavaScript, with JavaScript being employed for DOM manipulation, handling user interactions, carrying out form validation and communicating with the backend APIs.
The backend makes use of Node.js and Express.js; it employs REST APIs for managing charging stations and bookings, and JSON is used for storing the application data since a database was not required for this assessment.
The project also features input validation, error handling and the use of appropriate HTTP status codes, and the API functionality was tested with Postman.

The application allows users to:

* View charging stations
* Search for stations
* Filter stations
* View station information
* Select a charging station
* Make a booking
* View bookings
* View individual booking details
* Update bookings
* Cancel bookings
* View booking status
